# 세계관 책 문장 검토

## 1. 문장 검사 (prose-style)

### 기준 말투
이 책은 세계 안에서 만든 책이다 ("아이파베스 대도서관 간행"). 본문은 담담한 설명체(~다)로, 프롤로그는 2인칭 현재형("당신은 ~한다")으로 쓴다. 현실 세계에 빗대는 설명과 RP 안내는 '캐릭터 설정' 부록에 둔다.

### 진단
| 상태 | 증상 | 예 |
|---|---|---|
| P6 말투가 섞임 | 세계 안의 책에 위키·설정집 말투가 끼어듦 | "이야기가 진행된다", "지금까지 언급된", "공무원 시험과 비슷한 개념", "아이템" |
| P2 뜻이 흐림 | 어디에 걸리는지 모르는 말, 한 문장에 세 겹 | "무역을 통틀어", 접점 의식의 꿈 문장, "4원소 학자들도"(대마법사도 죽은 것처럼 읽힘) |
| P1 추상적 | 구체적인 장면 없이 '무언가'에 기댐 | 프롤로그 "오래되고 깊은 무언가", "너무 많은 것" |
| P6 시제 | 현재형과 과거형이 오감 | "서 있는 이 공간은 … 품고 있었다", "읽는다. … 알 수 없었다" |
| P4 반복 | '다양' 7회, "~있다." 14회 (그중 "~수 있다" 6회) | |

### 교정 (반영함)
| 위치 | 원래 | 고친 뒤 |
|---|---|---|
| 프롤로그 | 처음 그 문 앞에 섰을 때, 당신은 아마 말문이 막혔을 것이다. | 처음 그 문 앞에 서면, 당신은 아마 말문이 막힐 것이다. |
| 프롤로그 | … 무언가가 그곳에 있었다. | … 무언가가 그곳에 있다. |
| 프롤로그 | … 너무 많은 것을 품고 있었다. | … 너무 많은 것을 품고 있다. |
| 프롤로그 | 누가 남긴 말인지, 처음엔 알 수 없었다. | 누가 남긴 말인지는 아직 알 수 없다. |
| 프롤로그 | 당신은 분명 무언가를 바라고 이 문을 넘었을 것이다. | 당신은 분명 바라는 것이 있어 이 문을 넘었을 것이다. |
| 학교 · 마을 | 5개의 명문 학교 중 하나인 아이파베스와 그 마을을 중심으로 이야기가 진행된다. … 대도시로 변할 수 있었다. … 무역을 통틀어 다양한 종족이 먹을 수 있는 맛집과 볼거리가 많아 … | 아이파베스는 5대 명문 학교 중 하나다. … 대도시가 되었다. … 이 도시에는 무역으로 온갖 물건이 들어오고, 어느 종족이든 먹을 수 있는 맛집과 볼거리가 많아 … |
| 학교 · 반 배정 | 반과 속성 배정은 교장이 아닌, … 결정한다. 입학 시 점성 선생님이 … 접점을 시도해주며, 점성 선생님을 통해 꾸는 꿈은 그들이 그려낸 환상이나 믿음 등 다양한 형태로 나타난다. 반의 이름 역시 그들이 직접 지정해준다. | 반과 속성은 교장이 정하지 않는다. … 정한다. 입학할 때 점성 선생님이 … 접점을 시도하면 학생은 꿈을 꾼다. 꿈은 그 존재가 그려 보이는 환상일 때도 있고, 그들이 품은 믿음일 때도 있다. 반의 이름도 그들이 직접 지어 준다. |
| 학교 · 선생님 | 지금까지 언급된 선생님은 다음과 같다. | 알려진 선생님은 다음과 같다. |
| 학교 · 도서관 | 모든 분류의 책이 구비되어 있다. | 모든 분야의 책을 갖추고 있다. |
| 학교 · 그랑프리 | 상금과 아이템이 주어진다. | 상금과 상품이 주어진다. |
| 학교 · 비서 시험 | 공무원 시험과 비슷한 개념이다. | 신들을 섬기는 관리를 뽑는 시험인 셈이다. |
| 학교 · 졸업 후 | 졸업 후의 길은 마법사만이 전부가 아니다. | 졸업생이 모두 마법사로만 사는 것은 아니다. |
| 마법 | 이 세계의 시민들은 종족이 다양하며, 마력을 자각한 존재를 마법사라 부른다. | 이 세계에는 여러 종족이 산다. 그중 마력을 자각한 존재를 마법사라 부른다. |
| 세계 · 향수 | 종류가 다양하며 주로 정령이 제조하고, … | 종류가 많고 주로 정령이 만들며, … |
| 세계 · 수호자 | … 형태는 다양하다. | … 모습은 저마다 다르다. |
| 소문 · 대마법사 | 4원소 학자들도 1000년이 넘는 시간 전에 세상을 떠났고, | 4원소 학자들은 1000년도 더 전에 세상을 떠났고, |

결과: '다양' 7회 → 2회. "동양의 성주신"은 세계 안에 동양관이 있으므로 그대로 둠.

### 고치지 않고 남긴 것 (작가 확인 필요)
- **그랑프리** "속성이 두 개인 반과 하나인 반": 속성은 학생마다 가지는데 '반의 속성 개수'가 무엇인지 설명이 없다. 뜻을 알아야 고칠 수 있다.
- **"100골드 = 약 10,000원 (한화 기준 환산)"**: 현실 세계에 빗댄 설명이지만 RP에 쓸모가 있어 둠. 부록으로 옮길지 결정.
- **"살고 싶은 마을 10위"**: 현대식 순위 표현. 의도한 유머라면 둠.
- **프롤로그의 구체성**: "오래되고 깊은 무언가"를 감각 묘사(문의 재질, 로비의 냄새 등)로 바꾸면 생생해지지만, 새 묘사를 더하는 일이라 작가가 정함.

## 2. 뻔한 요소 검사 (cliché-transcendence)

### 1단계: 장르 기본값 나열
의식으로 정하는 반 배정 / 반 대항전 / 엘리트 반 / 행방불명된 창립자 / 숨겨진 성물 네 권 / 무언가를 만들어 내려는 교단 / 졸업 보상으로 원하는 마법 하나

### 직교성 검사: "자기가 어떤 이야기 속에 있는지 아는가?"
| 요소 | 상태 | 이유 |
|---|---|---|
| 여신의 책 | 알고 있음 | 프롤로그가 "직접 확인하러 왔는가"라고 물어 학생의 목표로 정해 둠 |
| 대마법사의 행방 | 알고 있음 | 학생이 풀 비밀로만 존재 |
| 주선교 · 죄악교 | 반쯤 | 목적("만들어 내려 한다")은 있으나 학교와 엮이는 방식이 정해지지 않음 |
| 그랑프리, 마스터반 | 장르 뼈대 | 익숙함이 장점. 손댈 필요 적음 |

### 이미 신선한 요소 (참고할 결)
타로 연도 / 5초 배달 통판북 / 인간의 향수 / 주식 마법사 / 인간계 입국심사. 모두 학생과 상관없이 세계의 논리로 굴러간다.

### 대안 방향 (고르는 것은 작가)
- 여신의 책: 학생 말고도 다른 이유로 찾는 이가 있다 (목록을 완성하려는 사서, 값을 매기려는 상인 등)
- 교단: 학교와 무관한 자기 목적이 있고, 그것이 우연히 학교와 부딪힌다
- 뒤집기(선한 창립자 → 악한 창립자)는 피한다. 축을 바꾼다

### 흔한 문장
"말문이 막혔을 것이다", "끝이 보이지 않는 복도", "그리고 이제, 이 학교는 당신의 이야기가 되었다"
